# SQL Data Analytics Project

This repository contains an end-to-end data analytics project built using **SQL Server and Power BI**.

The project focuses on exploring sales, customer, and product data to uncover business insights through SQL analysis and interactive data visualization.

## Project Overview

The project uses a structured sales dataset to perform exploratory and advanced analytical analysis.

SQL is used to investigate the data, calculate key business metrics, identify trends, analyze customer and product performance, and answer real-world business questions.

The resulting insights are then presented through interactive Power BI dashboards.

## Tools & Technologies

* **SQL Server**
